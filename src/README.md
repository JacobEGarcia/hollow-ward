# HOLLOW WARD

An original survival-horror vertical slice for the browser. Flat FPS on desktop,
WebXR VR in the Quest 3 browser. Inspired by the tension and interaction style
of classic survival horror; all names, characters, and assets are original.

Built with Godot 4.7.2 (Compatibility renderer). See assets/models/ASSET_CONTRACT.md
for the Blender pack spec.
